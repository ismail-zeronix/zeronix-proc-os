## Arabic keyboard laptop or Windows Arabic: the difference

These are two separate things, and mixing them up causes most of the disappointment.

- **Windows keyboard language.** Windows 11 can type Arabic on any laptop: add Arabic in Settings, switch with a shortcut, and type. This works on an English-only keyboard.
- **Printed keys.** An Arabic/English keyboard has Arabic letters printed on the keys alongside the English ones. You cannot add that later by changing a setting.

For a few staff who type in Arabic occasionally, an English-only laptop with the Windows Arabic layout is enough. For anyone who types a lot in Arabic, or who is not a touch typist, printed keys matter.

## Why it is part of the part number

A laptop's part number identifies the whole configuration: processor, memory, storage, screen, warranty and keyboard. Manufacturers make different keyboards for different markets, and each is a different part number. Two laptops with the same name can have different keyboards, different memory and different warranty terms.

That is why a quotation that just says "EliteBook 840" is not enough. Ask for the part number.

## How to check the layout

1. **HP:** look for #ABV at the end of the part number, which marks an Arabic/English keyboard.
2. **Other brands:** ask the supplier to confirm the layout for the part number and to state it on the quotation.
3. **When it matters:** ask for a photo of the actual keyboard from the stock the order will come from.
4. **On delivery:** check one laptop from each batch before you hand them out, and report any mismatch the same day.

## Adding Arabic in Windows 11 (for every laptop, whatever the keys say)

Even with printed Arabic keys, the laptop still needs the Arabic input language installed. It takes a minute, and your IT team can set it in the standard image so staff never have to:

1. Open Settings, then Time & language, then Language & region.
2. Add Arabic (United Arab Emirates) as a language, and keep English as the main display language if staff work in English.
3. Switch between Arabic and English with the Windows key and Space, or with Alt and Shift.
4. Check the language shows in the taskbar so people can see which one is active.

If you manage laptops with Intune or a standard image, add the Arabic language and keyboard to the image once, and every laptop starts ready to type in both.

## Which staff really need printed Arabic keys?

Not everyone does. A useful rule for a company order:

- **Printed Arabic/English keys** for staff who write documents, emails and messages in Arabic every day: administration, government relations, legal and HR in many companies, and customer-facing teams.
- **English-only keys** for staff who work in English and only occasionally need Arabic. The Windows Arabic layout is enough for them.
- **A few spares of each** so a replacement matches what the person already uses.

Asking each team before you order takes a day and avoids a mixed-up delivery later. Put the answer in a small table of team, headcount and layout, and send it with your request so the quotation matches from the start.

## Ordering for a team with mixed layouts

1. Count how many people need Arabic/English keyboards and how many need English-only.
2. Add a small number of spares for each layout, so a replacement is the same as what the person had.
3. Put the quantities per layout on the order, not just a total.
4. Ask for the serial numbers by layout on the delivery note, so your IT team knows which laptop is which.
5. Standardise on as few models as possible. The same model in two layouts is easier to support than two different models.

## Common mistakes

- **Assuming "UAE stock" means Arabic keyboards.** Not every laptop sold in the UAE has Arabic keys. Ask.
- **Ordering by model name only.** The part number is what decides the keyboard.
- **Mixing layouts by accident in one order.** If you need both, say so and list quantities.
- **Leaving it until delivery.** A keyboard replacement after the fact costs more than getting it right at the start.
- **Forgetting backlit and non-backlit versions.** Some keyboards come with or without backlight. Ask if it matters to you.
